Демонстрационный проект визуализации карты нефтяного месторождения.
Создан для проверки возможности создания WEB приложения на основе имеющегося С++ кода. 
Показывает возможность написания WEB приложения для визуализации карт и геологических моделей.
Использует WebGL, позволяет гладко отображать достаточно сложные карты, с большим количеством вертексов.
Запуск https://mishelff.github.io/Emscripten_map_test/
