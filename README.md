Небольшой проект визуализации карты.
Создан для демонстрации возможности создания WEB приложения на основе имеющегося С++ кода визуализации карт и геологических моделей.
Использует WebGL, позволяет работать с достаточно сложными картами, с большим количеством вертексов.
Запуск https://mishelff.github.io/Emscripten_map_test/
